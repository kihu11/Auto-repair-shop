Название проекта: Автомастерская

Функциональные требования к проекту:

    Общее описание системы: Клиент-серверное веб-приложение для симуляции работы автомастерской.

    Вся логика выполняется прямо в браузере на обычном JavaScript.

    Интерфейс сделан на HTML и CSS.

    Архитектура разбита на понятные модули: модели данных, сервисы, репозитории и пользовательский интерфейс.

Хранение данных:

    Используется локальное хранилище браузера (localStorage) со списками механиков, заказов, гаражей и счетчиков.

    Все изменения сохраняются автоматически.

    При первом запуске загружаются начальные тестовые данные (6 механиков, 2 гаража, 2 заказа).

Сервисы:

    Работа с механиками: добавление, удаление, просмотр всех и только свободных.

    Работа с заказами: создание, закрытие, отмена, назначение механика, просмотр всех заказов.

    Работа с гаражом: добавление гаражей, просмотр списка, расчет свободных и занятых мест.

Интерфейс (одна страница):

    Блок статистики: общее число заказов, количество механиков и занятость мест в гараже.

    Таблица механиков: ID, имя, опыт, статус, текущий заказ, а также кнопки добавления и удаления.

    Таблица заказов: ID, название, машина, дата, цена, статус, назначенный механик и кнопки управления.

    Блок гаража: визуальный список гаражных боксов.

Технологический стек:

    Языки: JavaScript, HTML5, CSS3.

    Инструменты: редактор VS Code, локальный сервер Live Server, инструменты разработчика в браузере (DevTools) для отладки, проверки хранилища и запросов.
